01 / CONTEXT

从人工检索，走向候选驱动的分类决策。

Photo Taxonomy 5.0 类目层级深、相似边界多。标注员需要反复检索规则并比较近似类目，判断成本高，结果也容易受到经验差异影响。

核心判断

模型暂不适合直接替代人工，但可以先缩小候选范围，把复杂的开放式检索转化为更高效的有限选择。

02 / OBJECTIVE

先保证正确答案进入候选，再提升标注效率。

项目不以无人审核的全自动分类为当前目标，而是构建稳定的辅助标注 Copilot，在质量不劣化的前提下缩短单条任务的判断路径。

01Recall First

以 L2 Recall 为首要模型指标，优先降低正确类目的漏召风险。

02Human Control

输出经过排序的 Top-3 候选，由标注员保留最终决策权。

03Closed Loop

将错误自动归因并转化为 Prompt 与边界规则的下一轮迭代输入。

03 / CORE WORK

从数据、Agent 到实验验证的完整建设链路。

01
数据与类目治理

清洗训练数据，确定高优类目，并建立固定集与滚动集的双周评估机制。

02
分层 Agent 架构

搭建 L1 召回、L2 候选生成和 L3 冲突仲裁，并补齐异常、重试与上报链路。

03
Prompt 与自动 RCA

建立七层 Prompt 规则框架和九类 RCA 体系，让 Bad Case 持续回流为修正规则。

04
离线评测与 A/B Test

以 Recall 验证候选质量，再以 AHT 为核心指标、质量指标为护栏验证辅助标注收益。

DEPLOYMENT MODE

Candidate-first Copilot

向标注员展示置信度排序后的候选，减少检索 Taxonomy 和判断相似类目的成本。

WHY L2

Recall before automation

L3 最终 Top-1 准确率为 52.9%，因此当前阶段应优先保证 GT 进入 L2 候选集，再由人工完成确认。

NEXT OPTIMIZATION

Recover missed GT

继续围绕 L2 漏召类别补充 recovery、boundary 和 exclusion 规则，同时控制平均候选数量。
