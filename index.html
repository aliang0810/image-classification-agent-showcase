PROJECT CONTEXT

项目背景

01

端到端 Top-1 暂不足以支撑全自动分类。

Photo Taxonomy 5.0 类目层级深、相似边界多。标注员需要反复检索规则并比较近似类目，判断成本高，结果也容易受到经验差异影响。

52.9% L3 Top-1 Accuracy 不满足无人审核要求
86.5% L2 Candidate Recall 适合候选辅助标注
核心判断

保留人工最终决策，将模型能力用于缩小候选范围，把开放式类目检索转化为更高效的有限选择。

03 / RCA · FEEDBACK LOOP

自动 RCA 驱动规则迭代

从评测差异中识别失败层、归因根因并生成修正动作，经定向回归验证后进入下一版基线。

01 / DETECT

发现差异

对齐 Prediction、GT 与候选排序，定位失败层级。

02 / DIAGNOSE

自动归因

按 A–I 顺序判定错误来源，输出唯一 RCA Code。

03 / PATCH

生成修正

将根因转化为 Definition、Boundary 或 Priority 规则。

04 / VERIFY

定向回归

使用 Focus Set 验证修正，达标后进入新基线。

部署模式

候选优先的辅助标注

向标注员展示置信度排序后的候选，减少检索 Taxonomy 和判断相似类目的成本。

为什么选择 L2

先提高召回，再考虑自动化

L3 最终 Top-1 准确率为 52.9%，因此当前阶段应优先保证 GT 进入 L2 候选集，再由人工完成确认。

下一步优化

持续修复 GT 漏召

继续围绕 L2 漏召类别补充 recovery、boundary 和 exclusion 规则，同时控制平均候选数量。
