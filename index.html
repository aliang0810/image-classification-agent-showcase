01AGENT / DECISION ENGINE

分层分类的 决策架构

三个专业子 Agent 各自承担单一职责，通过稳定字段协议完成从候选召回到最终仲裁的完整决策链。

01 / RECALL

L1 Candidate Recall

从图片和标题中召回一级类目，为后续细分选择正确的 Taxonomy 子树。

高召回 · 多路由 · 可重试
02 / ROUTING

L2 Subtree Routing

按 L1 类目循环加载专属 Prompt，在受限范围内生成并排序叶子候选。

动态 Prompt · 循环执行 · Top-3
03 / DECISION

L3 Final Decision

结合候选定义与优先级规则完成最终仲裁，并对异常结果进行自动补偿。

规则裁决 · 单候选跳过 · Trace
